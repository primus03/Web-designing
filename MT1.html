HTML Tags and Their Definitions

<html>
The html tag is the root element of an HTML document.
<!-- comment -->
Comments explain the code and are not displayed on the webpage.
<head>
The head tag contains metadata about the webpage.
<title>
The title tag specifies the webpage title shown in the browser tab.
<body>
The body tag contains the visible content of a webpage.
<!DOCTYPE html>
It tells the browser to use standards mode for modern HTML.
<h1>
The h1 tag defines the main heading of a webpage.
<h2>
The h2 tag defines a second-level heading.
<p>
The p tag defines a paragraph of text.
