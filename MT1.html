    HTML Tags and Their Definitions

  1. html tag
    2. Definition: The html tag is the root element of an HTML document. It wraps all the content on the entire page and is used to define the beginning and end of an HTML document.
  2. comment tag
    3. Definition: Its contents are generally not displayed on the webpage itself.
  3. title tag
    4. Definition: The title tag specifies the title of the webpage. The title usually appears in the browser tab, it increases the visibility of the webpage.
  4. body tag
    5. Definition: The body tag contains the content of a webpage, such as headings, paragraphs, images, and links.
  5. !DOCTYPE html
    6. Definition: It tells the browser that the document uses which version of html.
  6. h1 tag
    7. Definition: The h1 tag defines the main heading of a webpage.
  7. h2 tag
    8. Definition: The h2 tag defines a secondary heading of a webpage.
  8. p tag
    9. Definition: The p tag defines a paragraph of text in a program.
